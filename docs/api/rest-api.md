# REST API Reference

## Load Balancer APIs

### Route Request

| Property | Value |
|----------|-------|
| Method | GET |
| Endpoint | `/api/loadbalancer/route` |

Routes a request using the currently selected load balancing algorithm.

---

### Get Current Algorithm

| Property | Value |
|----------|-------|
| Method | GET |
| Endpoint | `/api/loadbalancer/algorithm` |

Returns the currently active routing algorithm.

---

### Change Algorithm

| Property | Value |
|----------|-------|
| Method | POST |
| Endpoint | `/api/loadbalancer/algorithm/{algorithm}` |

Supported values:

- ROUND_ROBIN
- WEIGHTED_ROUND_ROBIN
- LEAST_CONNECTIONS

Example:

```http
POST /api/loadbalancer/algorithm/ROUND_ROBIN
```

---

### Reset Connections

| Property | Value |
|----------|-------|
| Method | POST |
| Endpoint | `/api/loadbalancer/reset` |

Resets active connections for all simulated servers.

---

# Simulation APIs

### Start Simulation

| Property | Value |
|----------|-------|
| Method | POST |
| Endpoint | `/api/simulation/start` |

Starts request generation.

---

### Stop Simulation

| Property | Value |
|----------|-------|
| Method | POST |
| Endpoint | `/api/simulation/stop` |

Stops request generation.

---

### Simulation Status

| Property | Value |
|----------|-------|
| Method | GET |
| Endpoint | `/api/simulation/status` |

Returns whether the simulator is currently running.

---

# Server APIs

### Get Servers

| Property | Value |
|----------|-------|
| Method | GET |
| Endpoint | `/api/servers` |

Returns all simulated servers.

---

### Add Server

| Property | Value |
|----------|-------|
| Method | POST |
| Endpoint | `/api/servers/add` |

Creates a new backend server.

---

### Remove Server

| Property | Value |
|----------|-------|
| Method | POST |
| Endpoint | `/api/servers/remove` |

Removes the last simulated server.

---

### Enable Server

| Property | Value |
|----------|-------|
| Method | POST |
| Endpoint | `/api/servers/{id}/enable` |

Marks the specified server as active.

---

### Disable Server

| Property | Value |
|----------|-------|
| Method | POST |
| Endpoint | `/api/servers/{id}/disable` |

Marks the specified server as inactive.

---
