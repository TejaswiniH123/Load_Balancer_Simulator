# Prerequisites

Install the following software before running the project.

| Software | Version |
|----------|---------|
| Java | 17 |
| Maven | 3.9 or later |
| Node.js | 18 or later |
| npm | Latest |
| Docker | Latest (Optional) |
| Git | Latest |

---

# Verify Installation

Java

```bash
java -version
```

Maven

```bash
mvn -version
```

Node.js

```bash
node -v
```

npm

```bash
npm -v
```

Docker

```bash
docker --version
```

If all commands execute successfully, the development environment is ready.
